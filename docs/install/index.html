3. Agent sẽ làm gì

  1. Kiểm máy chỉ đọc: Git, Python ≥ 3.10, Node ≥ 22, ffmpeg.
  2. Trình kế hoạch: thiếu gì, lệnh cài nào (winget trên Windows, brew trên macOS), clone vào đâu — rồi chờ bạn đồng ý.
  3. Clone repo vào thư mục người dùng (không thư mục đồng bộ đám mây), cài vào .venv của repo.
  4. Dựng trạm: mặc định workspace/ ngay trong repo, Git bỏ qua cả thư mục. Đã có trạm riêng thì chỉ thẳng thư mục đó.
  5. Chạy video-studio doctor và chép nguyên từng dòng cho bạn.
  6. Nếu máy đủ công cụ render và có repo giọng: dựng bài mẫu hai cảnh để chứng minh cả chuỗi.

4. Đọc kết quả kiểm tra

NhãnNghĩaViệc tiếp

NOT_CHECKEDChưa kiểm được — không phải lỗi, cũng chưa phải xác nhậnDòng render luôn ở mức này tới khi dựng bài mẫu

Bộ khung (lệnh, trạm, bộ test) đã chạy trên cả Windows và macOS. Render thật mới có số đo trên Windows; trên Mac, bài mẫu là phép thử đầu tiên — kết quả kỳ vọng ghi ở samples/news-mini/EXPECTED.md.
