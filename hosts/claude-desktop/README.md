# Claude Desktop (tab chat)

Tab chat của Claude Desktop **không chạy được lệnh**, và repo này không có MCP server để gắn vào
đó — nên tab chat không cài hay dùng được Agent Video Studio.

Hai cách thay thế:

- Dùng **tab Code** của chính ứng dụng Claude (là Claude Code): làm theo [Claude Code](../claude/README.md).
- Dùng [Codex](../codex/README.md) hoặc [Antigravity](../antigravity/README.md).

Muốn chỉ hỏi đáp trong tab chat: tự cài theo [START-HERE.md](../../START-HERE.md) trong terminal, rồi
dán kết quả `video-studio doctor` vào chat để được giải thích.
