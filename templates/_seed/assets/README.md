# `assets/` của project

Ảnh, clip, font riêng của project này. Composition tham chiếu bằng **đường tương đối**
(`assets/anh.png`), không bao giờ bằng đường tuyệt đối.

Repo không mang theo file media nào (xem `.gitignore`), nên thư mục này đến tay bạn ở dạng rỗng —
đó là chủ ý: tài sản là của bạn, và nó thuộc về trạm chứ không thuộc về repo.
